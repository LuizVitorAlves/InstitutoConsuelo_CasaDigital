# Comandos SQL
### CREATE TABLE
---
Cria uma nova tabela no banco.

Pra que serve?

Definir as colunas, tipos e estrutura inicial.

### INSERT INTO
---
Insere linhas (registros) na tabela.

Pra que serve?

Adicionar dados reais para trabalhar.

### SELECT
---
Consulta dados armazenados.

Pra que serve?

Buscar informações específicas com filtros, ordenações, etc.

### PDATE
---
Atualiza valores já existentes.

Pra que serve?

Corrigir um dado, mudar informação, ajustar valores.

### DELETE
---
Remove registros da tabela.

Pra que serve?

Limpar dados inúteis, apagar algo duplicado, remover registros inválidos.

### WHERE
---
Filtra registros em SELECT, UPDATE ou DELETE.

Pra que serve?

Garantir que você só mexa nos dados certos.

### JOIN
---
Une dados de duas ou mais tabelas.

Pra que serve?

Relacionar entidades (ex: cliente + pedido + produto).

### GROUP BY
---
Agrupa dados para usar funções de agregação (SUM, COUNT...).

Pra que serve?

Criar relatórios com somatórios, médias, contagens.

### ORDER BY
---
Ordena os resultados.

Pra que serve?

Mostrar resultados classificados (do maior pro menor, A–Z, etc.).
